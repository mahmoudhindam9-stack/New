# Black Screen Overlay

تطبيق Android صغير جدًا لزر عائم فوق التطبيقات.

## الاستخدام

1. افتح التطبيق.
2. فعّل **السماح بالظهور فوق التطبيقات**.
3. اضغط **تشغيل الزر العائم**.
4. سيظهر زر دائري `ON` فوق Facebook أو أي تطبيق آخر.
5. اضغط الزر: تتحول الشاشة إلى أسود كامل بينما يظل التطبيق والفيديو/الصوت أسفل الـOverlay مستمرًا.
6. للخروج من الأسود: اضغط مرتين بسرعة في أي مكان على الشاشة السوداء.

## ملاحظة

التطبيق لا يطفئ طاقة الشاشة فعليًا. هو يستخدم Window Overlay سوداء كاملة، لذلك يمكن أن يستمر تشغيل الفيديو دون الحاجة إلى إطفاء الشاشة الحقيقي.

## المشروع

- compileSdk 36
- targetSdk 36
- minSdk 26
- Android Gradle Plugin 9.0.1
- Gradle 9.1
- لا توجد مكتبات خارجية.

افتح المجلد في Android Studio حديث وسيقوم Gradle بتنزيل مكونات البناء المطلوبة.
